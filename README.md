# KPC 교육운영결과 & 만족도 분석 대시보드 (NPS)

한국생산성본부(KPC) 설문 로우데이터(`과정별설문결과_*.xlsx`)를 기반으로 **강사별 만족도** 및 **교육운영결과보고서**를 직관적으로 분석·조회하고, 원본 템플릿과 100% 동일한 서식의 수정 가능한 엑셀 파일(`.xlsx`)로 다운로드할 수 있는 대시보드 시스템입니다.

---

## 🌟 주요 기능

1. **실시간 검색 및 필터링**
   - **과정명 자동완성/검색**: 수백 개의 과정명을 실시간 검색하고 자동완성 지원
   - **강사별 만족도 모드**: 특정 과정 + 강사를 선택하여 차수별 추이 및 만족도 확인
   - **교육운영결과보고서 모드**: 과정 전체의 차수별 만족도 및 종합 지표 확인
   - **차수/월별 탭 전환**: 교육일정 시작 월 기준으로 시트(3월, 4월, 5월, 7월 등)를 원클릭 전환

2. **보고서 서식 완벽 미러링 (A4 리포트 뷰)**
   - 실제 엑셀 보고서 서식(개요 요약, 설문결과 분석 테이블, 6개 핵심 차트, 교육 운영 결과표)을 실물 그대로 웹 화면에 렌더링
   - **6개 핵심 차트 시각화**:
     1. ② 교육과정내용 만족도 추이 (차수별 누적 막대 그래프)
     2. ③ 추천지수(NPS) 추이 (차수별 누적 막대 그래프)
     3. ④ 교육생 직급 분포 (사원 ~ 임원)
     4. ⑤ 희망 교육형태 (오프라인, 비대면, 이러닝, 플립러닝)
     5. ⑥ 과정정보 출처 (SNS, 이메일, 홈페이지, 추천 등)
     6. ⑦ 교육운영 불편요소 (정보, 절차, 운영, 환경, 일정, 기타)

3. **인라인 주관식 의견 및 커리큘럼 편집**
   - 로우데이터에 없는 강사/교육내용/추천사유 주관식 의견을 대시보드 화면에서 바로 입력 및 수정 가능
   - 저장 시 데이터베이스에 영구 보관되며 엑셀 다운로드 파일에 자동 반영

4. **동일 양식 엑셀 다운로드 (수정 가능)**
   - 원본 샘플 엑셀의 서식, 폰트, 테두리, 배경색, 병합 셀 및 **6개 BarChart 객체**를 그대로 보존한 `.xlsx` 파일 즉시 다운로드

5. **지속적인 로우데이터 누적 업로드**
   - 웹 화면의 [로우데이터 업로드] 버튼을 통해 새 엑셀 파일을 드래그 앤 드롭하면, 기존 데이터와 자동으로 병합 및 누적 반영

## 🚀 빠른 시작 가이드

### 1. 원클릭 실행 (Windows)
프로젝트 폴더 내 `start_dashboard.bat`을 더블클릭하면 서버 가동과 동시에 웹 브라우저(`http://localhost:8000`)가 자동으로 열립니다.

### 2. 수동 실행 (터미널)
```bash
# 1) 패키지 설치
pip install -r requirements.txt

# 2) 서버 가동
python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
```
웹 브라우저에서 `http://localhost:8000`으로 접속합니다.
